✍️ Registro: Un administrador ingresa la dirección de un restaurante (ej: Av. Corrientes 1234).

🌐 Geocoding: Nuestro servicio viaja a la API de mapas para traducir ese texto.

📍 Coordenadas: Obtenemos la Latitud 🌐 y Longitud 🧭 exactas.

💾 Guardado: JPA guarda todo en la base de datos listo para que los usuarios busquen los restos más cercanos a su posición actual con un simple clic. ¡Adiós a perderse! 🍕🚀
